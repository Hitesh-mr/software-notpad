# 📝 Simple Text Editor (Python + Tkinter)

This project is a **basic text editor** created using Python's `tkinter` library.  
It allows users to **create new files, open existing text files, and save changes**, all within a lightweight GUI interface.

---

## ✨ Features
- 🆕 **New File** — Clears the editor for fresh text.
- 📂 **Open File** — Load and edit existing `.txt` files.
- 💾 **Save File** — Save text to a file of your choice.
- ❌ **Exit** — Close the application easily.
